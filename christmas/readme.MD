# 🎄 agac.py

A lightweight, 3D spinning ASCII Christmas tree that runs right in your terminal—complete with 170 twinkling lights, wrapped gifts, and falling sparkles. Built using only Python's standard library.

## Quick Start

No external packages needed. Just run:

```bash
python agac.py
```

Press `Ctrl + C` anytime to quit.

## What's Inside

* **Zero dependencies:** Pure Python (`math`, `random`, `time`, `shutil`).
* **Real-time 3D projection:** Z-buffered rotation at 30 FPS with directional light shading.
* **True-color ANSI:** Renders glowing ornaments, presents at the base, a shining star topper, and drifting snow.

## Tip

For the cleanest view, use a modern terminal with true-color support (Windows Terminal, iTerm2, GNOME Terminal, or VS Code) and widen the window to at least `116 × 44` characters.
